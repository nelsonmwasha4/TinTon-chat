# TinTon-Chat 🇹🇿

**App ya Chat halisi ya Kitanzania** - Watu wanachat, wanatuma zawadi za Coins, wanafanya Live ndani ya app.
**Hakuna Voice/Video Call** - Tumejikita kwenye Chat, Group na Live tu.

## ✨ Features

- 💬 **Chat ya Kweli** - Chat na marafiki papo hapo
- 👥 **Group** - Unda Group na marafiki wako
- 🎥 **Live** - Fanya Live na watu wakutazame ndani ya app
- 💰 **Wallet & Coins** - Tuma na pokea zawadi za Coins
- 🎁 **Rewards** - Pata zawadi kila siku
- 🌍 **Lugha Mbili** - Kiswahili na Kiingereza
- ⚙️ **Settings** - Privacy Policy, Terms, Futa Akaunti

## 🚀 Jinsi ya Kuitumia
